AKSHAY PRABHU PORTFOLIO

Files:
- index.html
- style.css
- script.js
- profile.png

To run in VS Code:
1. Open this folder in VS Code.
2. Install the "Live Server" extension by Ritwick Dey.
3. Right-click index.html.
4. Click "Open with Live Server".
5. The website opens in your browser.

Optional:
Put your resume PDF in this same folder and name it:
resume.pdf

Then the Download Resume button will work.

Important:
Replace the # placeholders for LinkedIn and GitHub with your real profile URLs.
